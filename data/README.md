# Yerel veri dizini — kamuya açık depoya veri koymayın

Ham/veri kaynağı çalışma kitapları bu GitHub/Zenodo arşivine **bilinçli olarak dahil edilmemiştir**.

Orijinal betiklerin Colab'da beklediği dosya adlarından biri:

`Veri_Seti_Son_duzeltilmis_v3_agac_farklari_eklendi.xlsx`

Betikleri çalıştırmak için yalnızca yetkili olarak eriştiğiniz dosyayı **özel çalışma ortamına**, örneğin Colab `/content/` dizinine yükleyin. **GitHub'a yüklemeyin.** Çalışma kitaplarından hangisinin tek ve nihai veri sürümü olduğu ayrıca araştırmacı tarafından belgelenmelidir.

Depodaki `.gitignore` dosyası Excel dosyalarının yanlışlıkla eklenmesini engellemeyi amaçlar; yine de yükleme öncesi dosya listesini kontrol edin.
